# Концепты Atomic Habits (для реализации в трекере)

## Петля привычки

Cue → Craving → Response → Reward.

- Cue: триггер, запускающий поведение.
- Craving: мотивационная сила, желание изменения состояния.
- Response: само действие (привычка).
- Reward: удовлетворение, закрепляющее связь с cue.

## Четыре закона изменения поведения

Создание хорошей привычки:

1. Make it Obvious (сделай очевидным) — cue.
2. Make it Attractive (сделай привлекательным) — craving.
3. Make it Easy (сделай лёгким) — response.
4. Make it Satisfying (сделай приятным) — reward.

Разрушение плохой привычки (инверсия):

1. Make it Invisible (сделай невидимым).
2. Make it Unattractive (сделай непривлекательным).
3. Make it Difficult (сделай трудным).
4. Make it Unsatisfying (сделай неприятным).

## Ключевые практики (по законам)

### 1-й закон: Make It Obvious

- **Habit Scorecard**: выписать текущие привычки, чтобы осознать их.
- **Implementation intentions**: «Я буду [ПОВЕДЕНИЕ] в [ВРЕМЯ] в [МЕСТО]».
- **Habit stacking**: «После [ТЕКУЩАЯ ПРИВЫЧКА], я буду [НОВАЯ ПРИВЫЧКА]».
- **Environment design**: сделать cue хороших привычек видимыми; убрать cue плохих.

### 2-й закон: Make It Attractive

- **Temptation bundling**: связать нужное действие с приятным.
- **Culture**: присоединиться к группе, где желаемое поведение — норма.
- **Motivation ritual**: сделать что-то приятное непосредственно перед трудной привычкой.

### 3-й закон: Make It Easy

- **Two-minute rule**: новая привычка должна занимать меньше двух минут на старте.
- **Reduce friction**: уменьшить количество шагов до действия.
- **Prime environment**: подготовить пространство заранее.

### 4-й закон: Make It Satisfying

- **Habit tracking**: отмечать выполнение; цепочка не должна прерываться.
- **Never miss twice**: одно пропускание допустимо; два подряд — начало новой (плохой) привычки.
- **Immediate reward**: добавить маленькое вознаграждение сразу после действия.

## Identity-based habits

- Цель — не «сделать X», а «стать человеком, который делает X».
- Каждое действие — голос за желаемую идентичность.
- Формула: «Я — тот, кто [ПОВЕДЕНИЕ]».

## 1% better / системы vs цели

- 1% улучшения ежедневно → 37x за год.
- Не цель, а система: «Вы не поднимаетесь до уровня своих целей. Вы опускаетесь до уровня своих систем».
