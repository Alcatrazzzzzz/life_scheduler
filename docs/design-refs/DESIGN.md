# DESIGN.md — дизайн-система claude.com

Источники: `claude-code.png`, `claude-code_2.png`, `claude-code_3.png`, `claude-code_4.png`,
`claude-code_5.png` (все в `docs/design-refs/`). Структура документа — Stitch/extraktor:
характер → палитра → типографика → компоненты → сетка → глубина → состояния → адаптивность → промпт агенту.

## 0. Источники и метод

| Файл | Размер | Что на нём |
|---|---|---|
| `claude-code.png` | 1280×720 | Светлая тема. Страница «Claude unavailable in region»: шапка, служебная полоса, hero с заголовком, абзацем и одной кнопкой |
| `claude-code_2.png` | 1831×981 | Тёмная тема. Главная: навигация, центральный hero «Give Claude more», три контрола в ряд, декоративные плашки |
| `claude-code_3.png` | 1839×990 | Тёмная тема. Enterprise: заголовок «The frontier, on every desk», две кнопки, ряд логотипов клиентов |
| `claude-code_4.png` | 1850×988 | Тёмная тема. Главная с открытым мега-меню «Developers» |
| `claude-code_5.png` | 1833×994 | Тёмная тема. Product → Claude Code: hero из двух колонок, встроенное окно приложения, плитки платформ |

Метод: попиксельный разбор PNG (декодер, гистограмма точных цветов, компоненты заливок,
горизонтальные/вертикальные проекции, замер скруглений по инсету первого ряда) + Windows OCR
для текстов и координат подписей.

Пометки в документе:

- **(измерено)** — число получено из пикселей, погрешность ±1 px для геометрии и ±2 для цвета.
- **(оценка)** — выведено из замеров (например, кегль из высоты чернил); требует сверки глазами.
- **(выведено)** — в референсах этого нет; значение добавлено для нужд приложения.

Важные ограничения:

- **Живой сайт из этой сети недоступен** (`claude.com` сбрасывает соединение), поэтому extraktor
  по URL не запускался — источником служат готовые скриншоты.
- В `claude-code.png` светлая тема представлена **только страницей ошибки**: на ней есть шапка,
  две кнопки и типографика, но нет полей, карточек, меню и списков. Всё, кроме кнопок,
  измерено на тёмной теме; светлые варианты остальных компонентов — инверсия той же геометрии.
- **Шрифт, начертание и межбуквенные интервалы по расту не измеряются.** Размеры выведены из
  высоты чернил строки и помечены `(оценка)`. Гарнитуру берите из стека проекта.
- **Анимации на статичных скриншотах отсутствуют.** Раздел 8 — рекомендации, а не замеры;
  все токены движения помечены `(выведено)`.

## 1. Характер (Visual Theme)

Тёплая монохромная система. Фон — кремовый в светлой теме и почти-чёрный с тёплым подтоном
в тёмной; иерархия строится на 1 px линиях и ступенях заливки, а не на тенях. Радиусы
низкие: 6–10 px, «таблеток» нет. Единственный цветной акцент — терракотовый знак логотипа;
кнопки, ссылки и состояния монохромны. Главный «приподнятый» элемент — сплошная тёмная
(в тёмной теме — светлая) кнопка с инверсным текстом. Маркетинговые страницы просторные,
с центрированной широкой колонкой и крупным hero-кеглем; продуктовый экран — плотный,
с двухколоночным окном приложения 16:9.

### 2.4 Правила использования цвета

- Акцент **никогда не используется как заливка кнопки или ссылки** — только логотип и рамка фокуса.
- Основная кнопка — инверсия фона: в светлой теме заливка `#141413`, в тёмной `#faf9f5`.
- Вторичная кнопка — заливка `#30302e` + граница `#3d3d3a` (только тёмная тема).
- Третья ступень — ghost: прозрачный фон, граница `#3d3d3a`.
- Иерархия блоков — 1 px линия и разница заливок на 5–10 % яркости, не тень.
- Статусные цвета в референсах не встречаются. `danger` выведен из акцента и помечен как
  прикладной токен.

## 6. Глубина и эффекты (Depth & Effects)

- **Тени:** у кнопок, полей и карточек отсутствуют. Есть только у всплывающих слоёв:
  мега-меню — гало `#131312` ~4 px; окно приложения — `#131312`/`#121211` шириной 20–30 px.
  Многоступенчатых `box-shadow` и градиентов нет.
- **Границы:** 1 px, сплошные, на всю ширину блока. Светлая `#e8e6dc` / `#ebebeb`,
  тёмная `#3d3d3a` и разделитель `#313130`.
- **Скругления:** 0 — линии и таблицы; 6 — мелкие контролы и строки списка;
  8 — кнопки, поля, композер; 10 — панели и блоки кода; ~12 — плитки платформ.
- **Элевация** — только сменой заливки: `#141413 → #1a1918 → #1f1f1e → #262624 → #30302e`.
- **Декоративная маска страницы.** На `_5` правый край левой колонки плавно растворяется в фон
  (≈30 px): заливка primary и secondary кнопок уходит градиентом в `#141413`. Это приём
  маркетинговой страницы для стыка с окном приложения, **а не стиль контролов** — в компоненты
  не переносить.
- **Запрещено:** glow, glassmorphism, цветные рамки, градиентные кнопки, крупные тени.

## 8. Движение (Motion) — не измерено

Анимаций в PNG нет, поэтому **ни одна длительность или кривая не измерена**. Ниже — минимальный
набор, согласованный с характером системы: без пружин, без масштабирования карточек, без
параллакса. Все значения `(выведено)`.

| Токен | Значение | Где применять |
|---|---|---|
| `--duration-fast` | 120 ms | hover/pressed кнопок, смена цвета строки |
| `--duration-base` | 180 ms | появление меню/панели, фокусировка |
| `--duration-slow` | 240 ms | выдвижение drawer/модалки |
| `--ease-standard` | `cubic-bezier(0.2, 0, 0, 1)` | все переходы по умолчанию |
| `--ease-out` | `cubic-bezier(0.16, 1, 0.3, 1)` | появление всплывающих слоёв |

Правила:

- Анимируйте только `background-color`, `border-color`, `color`, `opacity` и `transform`.
- Всплывающие слои — `opacity` + `translateY(4px → 0)`. Без `scale`, без bounce.
- Списки и таблицы не анимируют появление строк.
- При `prefers-reduced-motion: reduce` отключайте `transform`-переходы; оставляйте
  мгновенную смену цвета.
- Не анимируйте тени: их в системе нет.

## 9. Do / Don't

**Do**

- Стройте иерархию линиями и ступенями заливки, а не тенями.
- Держите одну primary-кнопку на экран и делайте её инверсией фона.
- Используйте акцент точечно: логотип и рамка фокуса.
- Сохраняйте радиусы 6/8/10; кнопка — 8 px, панель — 10 px.
- Для тела текста берите вторичный цвет (`#5e5d59` / `#87867f`) — так в референсах.
- Проверяйте контраст приглушённого текста: `#9c9c99` и `#75746f` только для неинформативных подписей.
- В тёмной теме заменяйте тени более светлой заливкой поверхности.

**Don't**

- Не заливайте кнопки и ссылки акцентом `#d97757`.
- Не делайте pill-кнопки (`radius = h/2`) и радиусы больше 12 px у контролов.
- Не добавляйте тени, glow, glassmorphism и градиенты.
- Не используйте чистый `#000`/`#fff`: палитра тёплая, крайние значения — `#141413` и `#faf9f5`.
- Не ставьте статусные цвета в один ряд с акцентом: danger — отдельная прикладная роль.
- Не увеличивайте кегль body сверх 22 px на маркетинговых страницах и 16 px в приложении.
- Не анимируйте списки и таблицы; не используйте bounce-кривые.

## 10. Адаптивность (Responsive Behavior)

Мобильных скриншотов нет, поэтому брейкпоинты **не измерены**. Рекомендация, согласованная
с существующим фронтендом:

| Диапазон | Поведение |
|---|---|
| ≥ 1200 px | Полная шапка, hero в две колонки (текст + окно приложения), поля 60 px |
| 900–1199 px | Сворачивать навигацию в меню; поля 24–32 px; окно приложения под текстом |
| < 900 px | Одна колонка; H1 44 → 32 px; композер и кнопки на всю ширину; плитки платформ 2–4 в ряд |
| Touch | Минимальная высота интерактивных целей 40 px (измеренные 36–40 — нижняя граница) |

Встроенное окно приложения (929×522) — декоративное; на мобильном его нужно заменять
реальным интерфейсом, а не масштабировать.
