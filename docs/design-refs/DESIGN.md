# Дизайн-токены по референсам

Источники: `docs/design-refs/claude-code.png` и `docs/design-refs/vercel.png` (оба 1280×720).

## Как получены значения

Скриншоты в этой сессии визуально недоступны, поэтому значения сняты попиксельным разбором PNG
(декодер + гистограмма цветов, карта плотности, построчные замеры). Отсюда две оговорки:

- **Цвета, размеры в пикселях, толщина линий, радиусы, отступы — измерены**, погрешность ±1 px.
- **Гарнитура, начертание (weight), межбуквенные интервалы — не измеряются по расту**. Размер шрифта
  выведен из высоты чернил строки (ink height) и округлён до типового значения; где значение выведено,
  а не измерено напрямую, стоит пометка _(оценка)_.

Палитра взята из `claude-code.png`, как и просили. `vercel.png` использован для сетки, скруглений
и характера границ — там нейтральная серая шкала, её значения тоже приведены.

## 1. Палитра (claude-code.png)

Доли — процент пикселей от всего изображения (гистограмма точных цветов).

| Роль | Hex | Доля | Где встречается |
|---|---|---|---|
| Фон страницы | `#faf9f5` | 94.77 % | Тёплый кремовый, заливка всего полотна |
| Текст основной | `#141413` | 2.24 % | Заголовок H1, шапка, заливка CTA, нижняя полоса |
| Граница / хайрлайн | `#e8e6dc` | 0.28 % | Линии 1 px на всю ширину (y=84 и y=128) |
| Текст вторичный | `#5e5d59` | 0.25 % | Основной абзац под заголовком |
| Текст третичный | `#30302e` | 0.16 % | Редкие служебные подписи |
| Приглушённый текст | `#9c9c99` | — | Второстепенная строка в шапке (высота чернил 12 px) |
| Акцент | `#d97757` | 167 px | Только знак 22×24 px в левом верхнем углу шапки |

Важно про «пёстрые» цвета: в гистограмме есть `#5e78aa`, `#fac890`, `#ae7859`, `#e1f9f5` и ещё
десяток оттенков по ~200–270 px. Это **не палитра**, а субпиксельное сглаживание (ClearType) по
краям глифов — их bbox совпадает с текстовыми блоками. В токены они не идут.

Акцент используется крайне скупо: один маленький знак, ни одной акцентной заливки кнопки.
Все кнопки — чёрные.

## 2. Типографика

Замеры: высота чернил строки (ink height) и шаг строк (line pitch).

| Роль | Ink height | Размер | Line-height | Цвет |
|---|---|---|---|---|
| H1 (claude) | 61 px | **64 px** _(оценка)_ | **70 px ≈ 1.1** _(оценка)_ | `#141413` |
| Body (claude) | 23 px | **20 px** _(оценка)_ | **34 px = 1.7** (измерено: шаг строк 437→471→505) | `#5e5d59` |
| Навигация (claude) | 15 px | **15–16 px** | одиночная строка | `#141413` |
| Служебная строка (claude) | 12 px | **13 px** _(оценка)_ | одиночная строка | `#9c9c99` |
| Hero-заголовок (vercel) | 47–57 px | **56–64 px** | шаг строк 64 px | `#171717` |
| Body (vercel) | 15 px | **18 px** _(оценка)_ | **32 px ≈ 1.78** (шаг 363→395→427) | `#171717` / `#767676` |
| Навигация и футер (vercel) | 12 px | **14 px** _(оценка)_ | — | `#767676`, `#171717` |

Начертания — что видно по плотности заливки:

- H1 занимает 24.7 % площади своего бокса при высоте 61 px — это крупный кегль с умеренной
  толщиной штриха, не «тяжёлый» bold. Для заголовка разумно взять weight 500–600.
- Body занимает 6.9 % — обычное начертание (400).
- Гарнитуру по расту определить нельзя: serif/sans не различить. Для реализации берите
  существующий стек проекта, а не выдумывайте новый.

Межбуквенные интервалы по расту не измеряются. Косвенный ориентир: в референсах крупный заголовок
визуально плотный, поэтому для H1 уместен `letter-spacing: -0.02em`, для мелкого текста `0`.
Это рекомендация, а не измерение.

## 3. Отступы и сетка

`claude-code.png` (главная сетка для нашего приложения — она просторнее):

| Что | Значение | Как измерено |
|---|---|---|
| Боковой отступ контента | **60 px** | шапка и герой начинаются с x=59–60, справа симметрично |
| Высота шапки до линии | **84 px** | хайрлайн на y=84 |
| Вторая служебная полоса | **44 px** | линия y=128 минус линия y=84 |
| Знак в hero | **56 × 77 px** | bbox x 612–667, y 237–313 |
| Знак → H1 | **40 px** | 353 − 313 |
| H1 → абзац | **24 px** | 437 − 413 |
| Абзац → кнопка | **26 px** | 553 − 527 |
| Кнопка | **258 × 40 px** | x 511–768, y 552–592 |

`vercel.png` (плотнее, для служебных экранов):

| Что | Значение |
|---|---|
| Боковой отступ шапки | **24 px** (элементы начинаются с x=24–28) |
| Высота шапки | **47 px**, CTA — **137 × 32 px** |
| Отступ контентной колонки | **60 px** |
| Шаг строк body | **32 px** |

Ритм, который вытекает из замеров: **24 / 32 / 40 / 60 px**. Промежуточные 4/8/12/16 px в
референсах на глаз не встречаются, но как шаг сетки они безопасны.

## 4. Скругления

| Элемент | Радиус | Обоснование |
|---|---|---|
| Кнопка (claude, h=40) | **8 px** | на y=553 (1 px от верха) левый край смещён на 4 px внутрь, полная ширина — с y=561 |
| CTA в шапке (claude, h=38) | **6–8 px** | тот же характер кривой |
| CTA (vercel, h=32) | **6 px** | верхняя строка уже полной ширины на 5 px с каждой стороны |
| Хайрлайны, таблицы | **0** | линии строго 1 px на всю ширину |

Пропорция устойчивая: радиус ≈ 0.15–0.2 от высоты элемента. Крупных «таблеток» (radius = h/2)
в референсах нет.

## 5. Границы и тени

- Тени **не обнаружены**. Вокруг панелей и кнопок нет многоступенчатого градиента: соседние пиксели
  либо фон, либо 1 px сглаженный край. Разделение делается контрастом заливок и линиями.
- Границы — **1 px**, сплошные, на всю ширину блока: `#e8e6dc` на кремовом, `#ebebeb` на сером.
- Единственный «приподнятый» элемент — сплошная тёмная кнопка (`#141413` / `#171717`) с инверсным
  текстом. Она и создаёт акцент вместо тени.
- Цветных рамок, glow, glassmorphism нет.

## 6. CSS-токены

```css
:root {
  /* Поверхности */
  --color-bg: #faf9f5;
  --color-surface: #fbfbfb;
  --color-surface-raised: #ffffff;

  /* Текст */
  --color-text: #141413;
  --color-text-secondary: #5e5d59;
  --color-text-muted: #9c9c99;

  /* Инверсия (единственный акцентный элемент — тёмная кнопка) */
  --color-inverse-bg: #141413;
  --color-inverse-text: #faf9f5;

  /* Линии */
  --color-border: #e8e6dc;
  --color-border-neutral: #ebebeb;
  --border-width: 1px;

  /* Акцент: используются точечно, не для заливок */
  --color-accent: #d97757;

  /* Скругления */
  --radius-control: 8px;
  --radius-control-sm: 6px;

  /* Сетка */
  --space-1: 4px;
  --space-2: 8px;
  --space-3: 12px;
  --space-4: 16px;
  --space-6: 24px;
  --space-8: 32px;
  --space-10: 40px;
  --space-15: 60px;

  /* Типографика */
  --font-display-size: 64px;
  --font-display-line: 70px;
  --font-display-tracking: -0.02em;
  --font-body-size: 20px;
  --font-body-line: 34px;
  --font-nav-size: 15px;
  --font-meta-size: 13px;
  --font-weight-display: 550;
  --font-weight-body: 400;
}
```

## 7. Замечания для нашего проекта

- Токены применены: `src/Web/src/index.css` (палитра, шкала, базовая типографика) и
  `src/Web/src/features/schedule/schedule.css` (компоненты). Прежний `--accent: #aa3bff` удалён.
  Тёмные значения — в §8, они выведены, а не сняты с референса.
- `--font-weight-display: 550` — нефракционный вес; он валиден только для вариативных шрифтов.
  Для обычных берите 500 или 600.
- Значения помечены как измеренные только там, где есть число из пиксельного замера. Всё, что
  подписано «_(оценка)_», стоит сверить глазами на макете, если он есть в исходном виде.

## 8. Тёмная тема (выведено, не измерено)

В референсах тёмной темы нет. Значения ниже выведены из светлых по правилу: тёплый оттенок фона
сохраняется (кремовый → тёплый почти-чёрный), относительная яркость инвертируется, акцент
осветляется, чтобы не проваливаться на тёмном фоне.

| Токен | Светлая (измерено) | Тёмная (выведено) | Контраст на фоне |
|---|---|---|---|
| `--color-bg` | `#faf9f5` | `#1f1e1c` | — |
| `--color-surface` | `#fbfbfb` | `#262523` | — |
| `--color-surface-raised` | `#ffffff` | `#2e2d2a` | — |
| `--color-text` | `#141413` | `#f5f4ef` | 15.13 |
| `--color-text-secondary` | `#5e5d59` | `#b8b6ae` | 8.20 |
| `--color-text-muted` | `#9c9c99` | `#8a8884` | 4.71 |
| `--color-border` | `#e8e6dc` | `#3a3936` | — |
| `--color-border-neutral` | `#ebebeb` | `#37373a` | — |
| `--color-inverse-bg` | `#141413` | `#f5f4ef` | 15.13 |
| `--color-inverse-text` | `#faf9f5` | `#1f1e1c` | 15.13 |
| `--color-accent` | `#d97757` | `#e2835f` | 6.06 |
| `--color-danger` | `#a8452c` | `#e08a72` | 6.38 |

Контрасты посчитаны по WCAG (relative luminance) для текста на `bg`.

## 9. Прикладные токены (не из референса)

Этих ролей в скриншотах нет — они нужны приложению, поэтому значения выведены и зафиксированы здесь.

| Токен | Значение | Почему |
|---|---|---|
| `--color-danger` | `#a8452c` / `#e08a72` | В референсах нет состояния ошибки. Оттенок выведен из акцента `#d97757`, контраст 5.61 (светлая) и 6.38 (тёмная) — проходит AA |
| `--font-page-title-size` | `44px` | 64 px (`--font-display-size`) — лендинговый hero-кегль. Для заголовка страницы приложения взят 44 px, пропорции сохранены: line-height 1.1, tracking −0.02em |

Ограничения по контрасту:

- `--color-text-muted` `#9c9c99` на светлом фоне даёт **2.61** — ниже AA. Допустим только для
  неинформативных подписей (прочерк, служебная метка). Всё, что несёт смысл, — `--color-text-secondary`
  (6.26).
- Акцент `#d97757` на светлом фоне — **2.96**: годится для маркеров и рамок фокуса, не для текста.
