# Сессия 2026-11-17 19-18

Добавил `docs/decisions/004-calendar-component.md` по шаблону ADR-lite:

- **Контекст** — почему таблица с сайдбар-формой перестала работать: не видно свободного времени и пересечений.
- **Решение** — собственный компонент без зависимостей: неделя по часам + месяц, форма в модалке (кнопка / клик по слоту / клик по дню), детали с удалением, бэкенд без изменений.
- **Альтернативы** — FullCalendar, react-big-calendar, «оставить таблицу», «форма в панели».
- **Последствия** — плюсы (контроль над вёрсткой, API не менялся) и честные минусы (~850 строк своего кода, упрощённый алгоритм пересечений, нет drag&drop, слоты вне tab-порядка, «ещё N» в месяце).
- **Когда пересмотреть** — drag&drop/повторения/таймзоны, тысячи событий в периоде, второй разработчик или тач-клиент.

Правило про плавные hover-заливки в ADR не дублировал — оно относится к дизайн-системе и уже зафиксировано в `DESIGN.md`, раздел 8.
