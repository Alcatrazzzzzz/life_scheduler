# Сессия 2026-11-23 21-24

ADR оформлен: `life_scheduler/docs/decisions/013-custom-date-time-select-fields.md`.

- **Контекст** — нативные date/time/select рисует браузер, они выбиваются из `DESIGN.md` и не подчиняются токенам.
- **Решение** — свои `DateField`, `TimeField` (ручной ввод + колонки), `SelectField` и общий `Popover`; пояснено, почему поповер рендерится без портала.
- **Альтернативы** — перекраска нативных, готовая библиотека, инлайн-календарь, только кнопки, абсолютное позиционирование, портал, `<label>`-обёртка.
- **Последствия** — плюсы (единый стиль, переиспользование, клавиатура) и честные минусы (свой код позиционирования/фокуса/a11y, неполный combobox, хрупкость `position: fixed`, дублирование date-хелперов, E2E-помощники).
- **Когда пересмотреть** — рост числа форм, a11y-аудит, мобильный как основной сценарий, диапазоны дат/часовые пояса, `transform` на предках.
