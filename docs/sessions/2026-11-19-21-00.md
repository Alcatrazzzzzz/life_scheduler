# Сессия 2026-11-19 21-00

Готово. Фича реализована, миграция применена к dev-базе, все гейты зелёные.

## Что сделано

**Хранилище (`Shared/Storage/`)**
- `IFileStorage` + две реализации: `S3FileStorage` (AWSSDK.S3 4.1.2, presigned PUT/GET) и `LocalFileStorage` (`App_Data/attachments`) для dev и тестов.
- Выбор драйвера через `Storage:Provider`; креды S3 — стандартная цепочка AWS, в конфиг не пишутся.
- Dev-эндпоинты `/api/storage/uploads|download/{id}` маппятся только в Development.
- Скачивание всегда `attachment` + RFC 5987 для кириллических имён.

**Вложения**
- Сущность `ScheduleAttachment` в `Features/Schedule/` (по CLAUDE.md, без `DbSet` в Shared) + конфигурация + миграция `AddScheduleAttachments`.
- `POST /api/schedules/{id}/attachments` → тикет загрузки; `confirm` → HEAD-проверка размера/типа; `download` → 302; `DELETE`.
- Лимиты: 25 МБ на файл, 10 файлов, 100 МБ суммарно; брошенные `Pending` старше часа чистятся.
- Файлы принадлежат записи целиком, то есть всей серии повторов.
- `GetSchedule` отдаёт `attachments`, `ListSchedule`/`ListHistory` — `attachmentCount`. Удаление записи удаляет и объекты.

**История**
- `GET /api/schedules/history`: прошедшие неповторяющиеся записи, новые сверху, `TimeProvider` для тестируемости.
- Вкладка «История», `HistoryView`, метка «Прошло» на неделе и в месяце; общий минутный `useNow` для живой смены статуса.
- `isEntryPast` — только для `recurrence === 'none'`; цвет прошедших поднят до `--color-text-secondary` ради контраста.

**Тесты**
- Бэкенд: полный цикл upload → confirm → download, лимиты, размеры, удаление объектов, история и границы «прошло».
- Фронтенд: 7 юнит-тестов `isEntryPast`, скрипт `npm test`, `vitest.config.ts`.
- E2E: создание прошедшей записи → «История» → вложение с кириллическим именем → скачивание → удаление.

## Важно

- Путь S3 скомпилирован, но вживую не проверялся: для него нужны бакет, креды и CORS на `PUT` с origin Vite. В dev и тестах работает локальный драйвер.
