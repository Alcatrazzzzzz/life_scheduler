# Сессия 2026-11-17 18-54

Готово. Форматирование на Ctrl+S настроено.

**Поставленные расширения** (устанавливаются в профиль VS Code, глобально):
- `ms-dotnettools.csharp` — форматирование C# через Roslyn
- `esbenp.prettier-vscode` — TS/TSX/JS/JSON/CSS/MD
- `dbaeumer.vscode-eslint` — авто-исправления ESLint на сохранении

**Созданные файлы:**
- `.vscode/settings.json` — `editor.formatOnSave: true`, дефолтный форматтер по языкам, `source.fixAll.eslint` на save, ESLint смотрит в `src/Web`
- `.vscode/extensions.json` — рекомендации, чтобы напарник получил тот же набор
- `src/Web/.prettierrc` — `semi: false`, `singleQuote: true`, `printWidth: 100`, `trailingComma: "all"`

Про `.prettierrc`: без него Prettier по умолчанию добавил бы точки с запятой и двойные кавычки — то есть первый же Ctrl+S переписал бы весь фронтенд. Конфиг подобран под текущий стиль кода.

**Проверки:**
- `npx prettier@3.6.2 --check "src/**/*.{ts,tsx,css}"` → `All matched files use Prettier code style!` — существующий код не тронется.
- `dotnet format --verify-no-changes` → exit 0. Расширения C# и CI-гейт используют один движок Roslyn с одними настройками (`.editorconfig` в репозитории нет), так что расхождений не будет.

**Что сделать вам:** перезагрузить окно VS Code (`Ctrl+Shift+P` → `Developer: Reload Window`) и открыть папку репозитория целиком, а не отдельные файлы — иначе `.vscode/settings.json` не подхватится.

Замечание: `.vscode/` не в gitignore, так что настройки можно закоммитить — тогда форматы будут одинаковыми у всех. Коммитить?
