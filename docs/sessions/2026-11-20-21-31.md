## Что изменилось

**`src/Web/src/features/schedule/queries.ts`**
- `useScheduleWindow(from, to)` — видимый период собирается из месячных батчей в кэше; недостающие месяцы запрашиваются сразу при навигации.
- `useSchedulePrefetch(enabled)` — после первой отрисовки последовательно догружает **+1…+12** и **−1…−3** месяцы (ближние первыми: +1, −1, +2, −2, +3, −3, затем +4…+12). При ошибке API очередь останавливается.
- `mergeWindowEntries()` — мерж + дедупликация по `id+date` (повторяющиеся серии приходят по вхождению на дату).
- Ключи батчей остались вида `['schedule','list',{from,to}]`, поэтому существующие `addToListCaches`/`invalidateQueries` работают без изменений.

**`src/Web/src/features/schedule/calendar.ts`**
- `monthRange()` — границы календарного месяца (батч).
- `monthsCovering()` — месяцы, покрывающие диапазон недели/сетки месяца.

**`src/Web/src/features/schedule/components/ScheduleCalendar.tsx`**
- `useSchedules` заменён на `useScheduleWindow` + `useSchedulePrefetch`; `keepPreviousData` больше не нужен.

**Тесты:** `calendar.test.ts` (+6 кейсов на `monthsCovering`/`monthRange`), новый `queries.test.ts` (+4 кейса на мерж, дедуп, сортировку).
