# Сессия 2026-11-17 19-16

Все три пункта исправлены.

**1. Разъезжающиеся разделители в строке «весь день».** Причина: тело сетки было отдельным вертикальным скролл-контейнером, и его ширина уменьшалась на ширину системного скроллбара, а шапка и «весь день» оставались на полную ширину. Отсюда накопление сдвига к 7-й колонке. Теперь шапка, «весь день» и часовая сетка лежат в одном скролл-контейнере, а строки шапки закреплены через `position: sticky` — все колонки всегда совпадают.

**2. Плавные hover-заливки.** Все заливки при наведении (кнопки, чипы, события, слоты и ячейки календаря) теперь анимируются через `--duration-base` (180 ms, `--ease-standard`) — раньше у слотов и ячеек перехода не было вовсе, а у кнопок было 120 ms. Отключается при `prefers-reduced-motion`.
Запомнил в двух местах:
- `docs/design-refs/DESIGN.md`, раздел 8: «Hover-заливки плавные… мгновенная заливка запрещена»;
- в память проекта — `feedback-hover-fills.md` (плюс индекс `MEMORY.md`).

**3. Двойные строки в часовом блоке.** Убрал получасовое дробление: один час = один кликабельный слот (168 вместо 336), подсветка при наведении — одна полоса на час. Создание из клика по слоту даёт 1 час (14:00 → 15:00), точное время по-прежнему правится в форме. Кнопка «Новая запись» создаёт запись на ближайшие полчаса длительностью 1 час.

**Проверки:** `npm run typecheck`, `npm run lint`, `npm run build`, `npm run e2e` (3/3), плюс ручная проверка в браузере: 168 слотов по 56 px, sticky-шапка держится при скролле, предзаполнение 14:00–15:00. Бэкенд не менялся.
