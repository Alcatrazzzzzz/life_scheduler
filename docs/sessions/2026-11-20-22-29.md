**Что изменилось:**
- Добавлена функция `Wait-ForPort` (`scripts/dev.ps1:62`) — тот же TCP-опрос, что раньше был только для Vite, вынесен в одну функцию для обоих портов.
- После `Start-Process dotnet watch` скрипт ждёт порт 5148 (до 120 с — холодная сборка `dotnet watch` бывает долгой). Если API не поднялся, выводится предупреждение, фронт не стартует, а `finally` всё равно убивает дерево процессов API.
- `npm run dev` и браузер открываются по той же схеме: фронт — после API, браузер — после порта 5173.
- Cleanup перенесён в общий `try/finally`, охватывающий всю последовательность; `$web` теперь может быть `$null`, это учтено при сборе `$rootIds`.
- Убрано дублирование цикла ожидания — Vite ждётся через `Wait-ForPort 5173 30`, поведение и сообщение о таймауте прежние.

**Проверки:** синтаксис скрипта — `Parser::ParseFile`, без ошибок; `Wait-ForPort` отдельно прогнан на закрытом порту (False) и открытом (True). Полный прогон `dev.ps1` не запускал, чтобы не открывать браузер на вашей машине — стоит один раз проверить вручную: `.\scripts\dev.ps1`.
