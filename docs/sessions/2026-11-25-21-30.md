# Сессия 2026-11-25 21-30

Реализовано по утверждённому плану. Голосовой помощник полностью локальный: Whisper.net + LLamaSharp в процессе .NET, без сетевых вызовов.

## Что сделано

**Backend**
- `Features/VoiceAssistant/` — `ProcessCommand` (multipart/JSON, retry, маршрутизация, запись в БД), `ToolDefinitions` (схемы, GBNF), `VoiceAssistantEndpoints`.
- `Shared/LocalAi/` — `WhisperTranscriber`, `LlmFunctionCaller` (Qwen + ChatML + GBNF), `AudioDecoder` (WAV и webm/opus через NAudio/Media Foundation, без ffmpeg), DI, eager-загрузка моделей.
- `Shared/Schedule/HabitNameMatcher.cs` — кириллица, падежи, префиксы, Левенштейн; SQLite `LIKE` для кириллицы не используется.
- `create_habit` приведён к реальной схеме БД; `ProcessCommand` — оркестрирующий срез без вызовов соседних срезов. Добавлен безопасный `unsupported` (422) вместо принудительной мутации.

**Frontend**
- `features/assistant/` — `api.ts`, `queries.ts`, `VoiceAssistant.tsx`, `assistant.css`.
- FAB на всех страницах, состояния idle/recording/processing/result/error, MediaRecorder (`audio/webm;codecs=opus`), автостоп 30 с, инвалидация кэшей после успеха, токены DESIGN.md.
- `App.tsx`, `--z-fab`, `playwright.config.ts` (E2E без моделей).

**Инфраструктура**
- NuGet: `Whisper.net` 1.9.1, `Whisper.net.Runtime` 1.9.1, `LLamaSharp` 0.30.0, `LLamaSharp.Backend.Cpu` 0.30.0, `NAudio` 3.3.0.
- `appsettings.json` → секция `LocalAi`; `.gitignore` → модели; `README.md` с URL моделей и troubleshooting.
