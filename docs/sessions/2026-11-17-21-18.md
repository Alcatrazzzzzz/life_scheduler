# Сессия 2026-11-17 21-18

Убрал трансформацию с кнопки и текста целиком — теперь рябить нечему.

**Что изменилось**
- Фон и рамка кнопки переехали на псевдоэлемент `.btn::before` («плашка», `inset: -1px`, `z-index: -1`, `border-radius: inherit`).
- На hover масштабируется только эта плашка (`scale(1.02)`); сама кнопка и её текст не трансформируются вообще, поэтому браузер не перерисовывает глифы.
- Варианты (`primary`, `secondary`, `ghost`, `row`, `danger`) переведены на `::before` для фона/границы; геометрия, цвета и hover-переходы прежние.
- Временные обёртки `.btn__label` из TSX убраны — правки в трёх компонентах откатились, остались только CSS-файлы.
- В reduced-motion плашка не масштабируется, переходы `::before`/`::after` отключены.

**Проверено в браузере**
- Текст: `Range` по содержимому кнопки даёт одинаковый прямоугольник `x=1075.125, y=125.75, 119.875×20` в покое и на hover — текст не двигается и не растрируется заново.
- Плашка: `none` → `matrix(1.02, 0, 0, 1.02, 0, 0)`; фон в тёмной теме `#faf9f5`, рамка ghost `#e8e6dc`, рамка danger при hover становится `--color-danger`.
- Пиксельная проверка области кнопки: тёмная заливка плашки + светлые глифы текста поверх — слои правильные.
- Мелкие `.btn--icon` не масштабируются (плашка остаётся `none`), у них только цвет/заливка.

**Команды**: `npm run build` и `npm run lint` — проходят. Dev-сервер и браузер закрыты, временный скриншот удалён.
