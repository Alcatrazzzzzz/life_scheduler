# Сессия 2026-11-17 21-08

Добавил масштабирование кнопки.

**Изменения** (`src/Web/src/index.css`)
- У `.btn` в `transition` добавлен `transform`.
- Новое правило `.btn:not(.btn--icon, .btn--row):hover:not(:disabled) { transform: scale(1.02) }` — кнопка подрастает на 2 %, рамка-кольцо при этом продолжает расходиться на 3 px.
- Селектор hover-рамки тоже сужен до `.btn:not(.btn--icon, .btn--row)`, поэтому прежняя заглушка `content: none` для мелких кнопок удалена — механизм один.
- При `prefers-reduced-motion: reduce` масштаб отключается (`transform: none`), рамка появляется без анимации.

**Проверено в браузере**: покой — `transform: none`; hover — `matrix(1.02, 0, 0, 1.02, 0, 0)` и рамка `top: -3px`; иконочная кнопка на hover — `transform: none`, рамка не раздвигается; в reduced-motion — `transform: none`, рамка на месте.

**Команды**: `cd src/Web && npm run build` — проходит. Dev-серверы (порты 5179/5180) и браузер закрыты.

Примечание: `transform` на hover расходится с рекомендацией DESIGN.md («без scale») — это осознанное отклонение по твоей просьбе.
