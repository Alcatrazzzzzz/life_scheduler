## Что сделано

Вместо таблицы со списком — полноценный календарь с двумя видами. Форма создания вынесена в модальное окно и вызывается тремя способами: кнопкой «Новая запись», кликом по получасовому слоту в сетке недели и кликом по дню в месяце / строке «весь день».

**Новые файлы**
- `features/schedule/calendar.ts` — арифметика дат, форматирование, раскладка пересекающихся событий по колонкам
- `components/ScheduleCalendar.tsx` — каркас: навигация по периодам, «Сегодня», переключатель «Неделя/Месяц», связка с диалогами
- `components/WeekView.tsx` — сетка 7 дней × 24 часа, клик по получасовому слоту, строка «весь день» для дел без времени, линия текущего времени
- `components/MonthView.tsx` — сетка 6×7, до 3 чипов в ячейке, клик по дню создаёт запись без времени
- `components/Modal.tsx` — модалка на нативном `<dialog>`, автофокус в первом поле, закрытие по Escape/клику по фону
- `components/CreateScheduleDialog.tsx` — форма с предзаполнением даты/времени из клика
- `components/ScheduleDetailsDialog.tsx` — просмотр дела и удаление
