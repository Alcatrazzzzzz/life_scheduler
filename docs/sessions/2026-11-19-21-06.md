# Сессия 2026-11-19 21-06

Готово — файлы теперь можно приложить прямо при создании события.

## Как работает

- В форме «Новая запись» появилась секция **«Файлы»**: выбор нескольких файлов, список выбранных с размером, удаление до сохранения.
- Лимиты проверяются сразу на клиенте (25 МБ на файл, 10 файлов, 100 МБ суммарно); сервер остаётся финальным валидатором.
- После успешного создания записи файлы загружаются по очереди по той же схеме ticket → PUT → confirm.
- Если запись создана, а загрузка файла упала, диалог не закрывается и не даёт создать дубль: показывается «Запись создана, но файлы не загружены: …» и кнопка «Закрыть». Остальные файлы можно догрузить потом в деталях.
- Во время сохранения поля блокируются через `fieldset`.
- Логика `uploadAttachment` вынесена в `api.ts` и переиспользуется секцией файлов в деталях; лимиты — в общем `attachmentLimits.ts`.
