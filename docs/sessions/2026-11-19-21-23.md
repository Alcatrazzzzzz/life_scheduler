# Сессия 2026-11-19 21-23

Нет, `dev.ps1` менять не пришлось — он уже запускает архиватор, потому что это не отдельный процесс, а hosted service внутри API.

- `scripts/dev.ps1` (как и `dev.sh`) стартует бэкенд командой `dotnet watch --project src/LifeScheduler.Api run --launch-profile http`.
- Архиватор зарегистрирован в `Program.cs` через `builder.Services.AddHostedService<HistoryArchiverService>()`, поэтому поднимается вместе с API.
- При старте он сразу делает первый проход (бэкфилл старых строк), затем тикает раз в минуту. Если что-то переведено, в логе API будет `В историю переведено записей: N`.
- Сама логика — `PastEntryArchiver`; она покрыта тестами, включая имитацию legacy-строки, которая была `Active` до появления флага.

То есть достаточно запустить `scripts/dev.ps1` (или `dev.sh`) — старые записи получат `Status = Archived` и `ArchivedAt` при старте API, без отдельного шага в скрипте.
