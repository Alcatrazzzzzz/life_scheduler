# Сессия 2026-11-20 21-07

Готово. В окне предпросмотра теперь можно переключаться между файлами.

## Что добавлено

- **Список файлов сверху** — горизонтальные вкладки с иконкой и именем. Появляется, когда файлов больше одного; клик сразу переключает предпросмотр.
- **Стрелки клавиатуры** — `←` / `→` переключают на предыдущий/следующий файл, с замыканием по кругу.
- **Кнопки навигации** и счётчик `2 / 4` рядом с размером файла — для мыши.
- Заголовок модалки и содержимое обновляются при каждом переключении; DOCX перерендеривается, PDF и картинки загружаются заново.

## Технически

- `AttachmentPreviewDialog` теперь принимает весь список `attachments` и начальный id, хранит выбранный файл внутри и рендерит тело предпросмотра отдельным компонентом с `key` — это сбрасывает состояние ошибок и корректно очищает Blob URL/DOCX-контейнер при смене файла.
- Логика соседнего файла вынесена в `adjacentAttachmentId()` в `attachmentPreview.ts` и покрыта тестами.
- `ScheduleDetailsDialog` хранит только `previewAttachmentId`.
- Стили вкладок — на токенах DESIGN.md, hover-заливка анимируется 180 ms, активная вкладка использует `--color-surface-selected` (в тёмной теме — `#3c3c3b`).

## Проверки

`typecheck`, `lint`, `npm run test -- --run` (16 тестов) — зелёные. В браузере проверил: клик по вкладкам, `←`/`→` с переходом через границу списка, счётчик, рендер PNG/PDF/DOCX и fallback для `.doc`, светлую и тёмную темы; ошибок в консоли нет. Тестовая запись удалена, серверы остановлены.
