# Сессия 2026-11-23 21-21

Исправил. Причина была в CSS: общий стиль `.schedule-form input` перебивал сброс у поля времени (у него специфичность выше), поэтому у внутреннего input оставались собственная рамка, фон и скругление — из-за этого иконка, «коробка» ввода и стрелка выглядели тремя отдельными элементами.

**Что изменено**

- `schedule.css`: стили формы теперь применяются только к `input`/`textarea` внутри `label` (название и заметки), а не ко всем полям формы.
- `fields.css`: сброс у поля времени усилен до `.field-input-group .field-input-group__input`, чтобы поле оставалось плоским даже внутри форм с общими стилями `input`.

Теперь рамку, фон и скругление рисует только сама группа: `[🕐 09:30 ▾]` — один цельный контрол. Фокус тоже подсвечивает группу целиком (2 px акцентом), а не отдельный input.

Проверил в браузере вычисленные стили: у внутреннего input `border: 0`, фон прозрачный, padding 0; у группы — одна рамка 1 px и скругление 6 px.

**Проверки:** typecheck, lint, build — чисто; Vitest 45/45; Playwright 5/5. Серверы и браузер остановлены.
