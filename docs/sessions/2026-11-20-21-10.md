# Сессия 2026-11-20 21-10

Готово: `docs/decisions/009-attachment-preview.md`.

ADR оформлен по шаблону проекта и покрывает все решения из этой сессии:

- **Контекст** — вложения уже есть (ссылка на ADR 007), но просмотр требовал скачивания; ограничение `Content-Disposition: attachment`; нежелание менять бэкенд.
- **Решение** — blob через существующий эндпоинт, object URL; `<img>` / нативный iframe для PDF / `docx-preview` для DOCX; fallback для `.doc`; TanStack Query с `gcTime: 0`; список файлов сверху + навигация стрелками.
- **Альтернативы** — прямая подстановка URL, отдельный inline-эндпоинт, `mammoth`, онлайн-просмотрщики, серверная конвертация `.doc`, кэширование blob-ов.
- **Последствия** — включая честные минусы: CORS на S3, отсутствие просмотра `.doc`, память под файл.
- **Когда пересмотреть** — если CORS недоступен, понадобятся другие форматы, миниатюры или авторизация.
